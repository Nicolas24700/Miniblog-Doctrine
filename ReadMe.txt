Ce qui a été développée : 
- La possibilité d'ajouter ou non une image pour un billet , si il y'a une erreur au niveau de l'image , le billet n'est pas publier.
– Lorsqu'un utilisateur n'est pas connecté. Dans le profil sera affiché un bouton , Vous n'êtes pas connecté 
– lorsqu'un utilisateur n'ayant pas les permissions administrateur se connecte, il ne verra pas la section admin dans la barre de navigation
– Lorsqu'un utilisateur est connecté, le texte du bouton Se connecter change en vous êtes connecté 
– Lorsqu'un utilisateur ou un billet est supprimé, cela supprime l'image enregistrée sur le serveur.
– Lorsqu'un utilisateur modifie sa photo de profil, cela remplace l'ancienne photo par la nouvelle, dans le cas où le format JPG, PNG soit le même que la photo de profil d'origine
