## 🚀 Installation
- Télécharger le projet
- Tapez :`composer install`

Une fois la configuration faite, vous devez générer la base de données et les tables à partir des entités définies dans le projet.

- Tapez :`vendor/bin/doctrine orm:schema-tool:create`
